# Pastelería SM - React

Migración del TP1 de HTML/CSS a una aplicación React creada con Vite.

## Tecnologías

- Vite
- React
- React Router
- CSS

## Cómo ejecutar el proyecto

1. Abrir una terminal en la carpeta del proyecto:

```bash
cd pasteleria-sm-react
```

2. Instalar dependencias:

```bash
npm install
```

En PowerShell de Windows, si `npm` aparece bloqueado por permisos de scripts, usar:

```bash
npm.cmd install
```

3. Levantar el servidor local:

```bash
npm run dev
```

O en PowerShell:

```bash
npm.cmd run dev
```

4. Abrir la URL que muestra la terminal, normalmente:

```txt
http://localhost:5173
```

## Funcionalidades

- Navegación con React Router.
- Componentes reutilizables.
- Cards generadas con props y `.map()`.
- Galería generada con `.map()` y `key`.
- Formularios controlados con `useState`.
- Envío con `event.preventDefault()`.
- Datos enviados visibles en la consola del navegador.
- Reset de formularios desde React.
